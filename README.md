# Ryde Drive

A Flutter-based Taxi Booking Driver App.

## Overview

Ryde Drive is a mobile application designed for taxi drivers to accept and manage ride requests, track their ride history, and communicate with passengers. This project focuses on the static design of the driver interface, showcasing the core layout and user interface elements.

## Features (Static Design)

- **Driver Dashboard**: Displays key information such as active rides, earnings, and status.
- **Ride Requests**: A section for drivers to view incoming ride requests with detailed information about the passenger, destination, and estimated fare.
- **Trip History**: Displays a list of completed rides with details like trip date, distance, and earnings.
- **Notifications**: A notification system for incoming ride requests and important updates.
- **Profile**: A section where drivers can view and edit their personal information, vehicle details, and settings.
- **Maps**: Static map design showing the driver's location, route to destination, and surrounding area.

## Installation

To get started with this project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/ryde_drive.git
   ```

2. Navigate to the project directory:
   ```bash
   cd ryde_drive
   ```

3. Install the necessary dependencies:
   ```bash
   flutter pub get
   ```

4. Run the app:
   ```bash
   flutter run
   ```

## Project Structure

- `lib/`: Contains the main application code.
  - `screens/`: Holds the different screen layouts for the app.
  - `widgets/`: Contains reusable widgets used across the app.
  - `models/`: Defines the data models used in the app.
  - `services/`: Handles any static or mock data fetching (used for demonstration purposes).

## Design & UI

This project implements a static UI for the following screens:

- **Login Screen**: Where the driver can log into the app.
- **Dashboard Screen**: Displays current ride status, earnings, and available actions.
- **Ride Request Screen**: Allows drivers to accept or reject ride requests.
- **Trip History Screen**: Lists completed trips along with details like fare and distance.
- **Profile Screen**: Displays the driver’s profile and allows editing.
